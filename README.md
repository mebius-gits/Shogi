# 櫻間 Shogi — 一局入心

可直接在瀏覽器遊玩的日本將棋遊戲。依使用者提供的參考圖，採用固定、略帶傾角的俯視棋盤，持駒在棋盤場景內各自一側橫排顯示：後手在上、先手在下，雙方頭像與玩家資訊放在棋盤左右；選單、設定、玩家資料與棋譜分頁顯示。這是獨立的正式對局專案，原本 `../3d anime/` 的美術展示保留。

## 開始遊玩

目前本機網址：**http://127.0.0.1:4174**

Windows 雙擊 `launch.cmd`，或在本資料夾執行：

```sh
npm start
```

需安裝 Node.js。網站使用的 Three.js 模組、角色頭像和材質都在專案內，**執行遊戲不需要 npm install、不需要外部 CDN、不需要帳號或 API 金鑰**。請用 HTTP 開啟，勿直接雙擊 HTML。若 4174 已被占用，可設定 `PORT` 後執行 server.mjs。

## 遊戲功能

- **對電腦／同機雙人**：可選先手、後手，三種電腦搜尋強度。
- **合法走法**：八種基本棋子、六種成駒、滑行阻擋、桂馬跳子、取子、持駒打入。
- **升變**：進入、離開或在敵陣三段內移動，可成／不成；步、香與桂的末段升變強制執行。
- **禁手防護**：阻止二步、打步詰、無處可走的打入、王手放置、自陷王手、越權與連續走兩手。不會先接受違規棋步再處罰。
- **終局**：將死、無合法步、投了、時間到、千日手、連續王手千日手、入玉宣言、500 手持將棋。
- **計時**：無限時、5 分鐘＋10 秒讀秒、10 分鐘＋30 秒讀秒。每手讀秒重設；動畫不扣雙方用時。
- **休閒操作**：提示、悔棋、暫停、逐手回顧、回到目前局面、KIF 棋譜下載。
- **自訂玩家**：雙方都能改名稱、上傳 PNG/JPG/WebP 頭像（最大 5 MB）。頭像會在瀏覽器縮成 192×192 圖片。
- **自動存檔**：棋局、姓名、頭像、計時、偏好皆儲存在瀏覽器 localStorage；重新開啟後按「繼續對局」。離開網站期間不計時。
- **和服落子動畫**：五指關節、捏棋與收手；先後手分別使用象牙櫻花、紫藤櫻花袖子。沒有身體或頭部模型，人物只出現在可自訂的小頭像。
- **光影**：春日、夕暮、月夜三種光線；棋盤、棋子、手和袖子均支援投影；陰影與音效可開關。
- **固定視角**：拖曳和滾輪不旋轉棋盤；手機仍維持左右頭像，雙方持駒各自橫排在場景內上方與下方。

電腦是本機 Web Worker 裡的輕量搜尋引擎，供休閒練習使用。這版提供本機人機與同機雙人對局，沒有網路配對或多人伺服器。

## 操作

1. 點自己的棋子，綠色位置是合法目的格；再次點該棋子可取消。
2. 點目的格落子；可升變時會出現「成／不成」選擇。
3. 取下的敵子回到自己的持駒區，並回復基本棋種。輪到自己時點持駒，再點合法空格打入。
4. 點右上「棋譜」，選一手或「從初始局面回顧」，在棋盤使用箭頭逐手瀏覽；按「返回對局」恢復操作。
5. 右上「選單 → 玩家資料」可修改雙方名稱與頭像。「開始新局」調整模式、棋力及用時，「棋室設定」調整光線、陰影、音效與動作。

棋盤格支援 Tab 聚焦與方向鍵移動焦點，Enter／空白鍵選取。Escape 可取消棋子選擇或關閉對話框。

離開棋盤到其他頁面會自動暫停。按選單的「繼續對局」，或返回棋盤後按「繼續對局」。分頁使用 #/play、#/menu、#/settings 等網址，支援瀏覽器上一頁與下一頁。升變選擇屬於思考時間，不會暫停計時。

## 規則選擇與來源

此遊戲採用平手將棋與**業餘 27 點入玉宣言制**：宣言者的玉在敵陣、未被王手、敵陣內除玉有至少 10 枚己子；敵陣己子與持駒計點（飛角各 5，其餘除玉各 1），先手至少 28 點、後手至少 27 點。未符合條件卻確認宣言會判負。此規則與職業賽的宣言制度有所不同，遊戲內指南有明確說明。

四次相同棋盤、持駒與手番構成千日手；如果循環間某方每次行棋都王手，該方判負。500 手後，在沒有王手時判持將棋。無勝負結果可換先後手開新局。

參考日本將棋連盟資料：

- [棋子移動、取子與升變](https://www.shogi.or.jp/knowledge/shogi/02.php)
- [各棋種與成駒走法](https://www.shogi.or.jp/knowledge/shogi/03.php)
- [禁手說明](https://www.shogi.or.jp/knowledge/shogi/05.php)
- [千日手、王手、終局與持將棋](https://www.shogi.or.jp/match/taikyoku_rules/)
- [業餘入玉宣言法](https://www.shogi.or.jp/faq/rules/)

這是可悔棋、暫停與使用提示的休閒棋室，不模擬競賽中的裁判流程。

## 檔案結構

| 檔案 | 功能 |
| --- | --- |
| `engine.js` | 純將棋規則、SFEN／USI、合法步產生、終局、歷史與驗證恢復 |
| `ai.js`、`ai-worker.js` | 限時迭代加深搜尋，在背景工作執行 |
| `clock.js` | 主時間、每手讀秒與時間快照 |
| `scene.js` | 固定輕微透視傾角、3D 棋盤、棋子、合法格、光線及陰影 |
| `hand.js` | 連續蒙皮手指與平滑關節、花紋和服袖子、手與棋子同步動畫 |
| `app.js` | 玩家設定、操作、存檔、對局 UI、分頁導航、升變與終局視窗、AI 排程 |
| `record.js` | UTF-8 KIF 匯出 |
| `index.html`、`style.css`、`pages.css` | 繁體中文 UI 與響應式排版 |
| `assets/koharu.png` | 前一版由內建 image_gen 生成的原創角色圖，供預設頭像使用 |
| `vendor/` | 本地 Three.js 0.180.0，MIT 授權見 `vendor/LICENSE` |
| `preview/` | 實際瀏覽器截圖與測試棋譜 |

棋盤使用索引 `row × 9 + column`；先手 side=0、向上，後手 side=1、向下。規則引擎沒有 WebGL 或 DOM 相依，可獨立測試與重用。

## 驗證

安裝開發依賴（僅測試需要）：

```sh
npm install
npm test
```

目前共有 **18 項規則／計時測試**，包括初始局面的 30、900、25,470 節點合法步樹驗證、所有棋種、取子與成駒、打步詰、王手、將死、千日手、宣言法及讀秒。

網站啟動後：

```sh
npm run test:browser
node tests/edge-browser.mjs
```

使用本機 Microsoft Edge headless 測試完整對局、電腦回應、違規阻止、升變／不成／強制升變、取子與打入、姓名與頭像、存檔恢復、KIF、回顧、悔棋、投了、將死、超時、玩家後手、取消過期 AI 工作、提示、固定視角、陰影、手機與和服動畫。

另與獨立套件 python-shogi 1.1.1 比對 **1,736 個種子生成的中盤局面**，每一局面的合法步集合均一致：

```sh
node tests/differential-fixtures.mjs
python -m pip install python-shogi==1.1.1
python tests/differential.py
```

Python 套件僅用於獨立交叉驗證，不是遊戲執行依賴。包含升變與打入的 KIF 已經由獨立 KIF 讀取器驗證。
