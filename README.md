# 櫻間 Shogi — 一局入心

可直接在瀏覽器遊玩的日本將棋遊戲，有三種模式：**電腦對戰**、**MQTT 連線對戰**、**同機雙人**。採用固定、略帶傾角的 3D 俯視棋盤，持駒在棋盤場景內上下兩側橫排顯示，雙方名牌放在棋盤左右。這是獨立的正式對局專案，原本 `../3d anime/` 的美術展示保留。

## 開始遊玩

目前本機網址：**http://127.0.0.1:4174**

Windows 雙擊 `launch.cmd`，或在本資料夾執行：

```sh
npm start
```

需安裝 Node.js。Three.js、MQTT.js、角色圖與材質都在專案內，**執行遊戲不需要 npm install、不需要外部 CDN、不需要帳號或 API 金鑰**（連線對戰只需要能連到 MQTT broker）。請用 HTTP 開啟，勿直接雙擊 HTML。若 4174 已被占用，可設定 `PORT`；要讓同一網路的其他裝置開啟，可設定 `HOST=0.0.0.0`。

## 流程

```
首頁 ─┬─ 電腦對戰 → 棋力／先後手／用時 ──┐
      ├─ 連線對戰 → 建立房間 或 輸入房號 ─┼→ 對局 → 終局：回顧・下載 KIF・再來一局・回到首頁
      └─ 同機雙人 → 對手名稱／用時 ───────┘
右上「設定」：玩家（名稱、頭像）／棋室（光線、音效、陰影、動畫、提示）／連線（broker）
```

- 對局一旦開始就不能中途離開再接回：重新整理或關閉頁面不會恢復棋局；對局中點標誌或按上一頁會先確認，連線對戰中離開視為投了。
- 頁首沒有棋譜入口；對局中棋盤左側即時顯示棋譜，終局後才能點選逐手回顧。
- 設定是覆蓋整個畫面的視窗，在首頁或對局中都能開啟；電腦與同機對局開啟設定時會自動暫停。
- 只有「玩家資料、偏好設定、各模式上次的選擇」會存在瀏覽器 localStorage，棋局本身不存檔。

## 模式

| | 電腦對戰 | 連線對戰 | 同機雙人 |
| --- | --- | --- | --- |
| 對手 | 花咲 小春（入門／初級／中級） | 另一台裝置的玩家 | 同一台裝置 |
| 提示・悔棋・暫停 | ✓ | — | ✓ |
| 入玉宣言・投了 | ✓ | ✓ | ✓ |
| 選為後手時棋盤翻轉 | ✓ | ✓ | — |

電腦是本機 Web Worker 裡的輕量搜尋引擎，供休閒練習使用。切到其他分頁時，電腦與同機對局會自動暫停。

## 連線對戰（MQTT）

預設 broker 為公開測試伺服器 `wss://broker.emqx.io:8084/mqtt`，可在「設定 → 連線」改成自己的 WebSocket broker（`ws://` 或 `wss://`）。公開伺服器上任何人都能訂閱主題，名稱與頭像會以明文傳送，只適合休閒對局。

1. 一方「建立房間」，選擇用時與先後手（先手／後手／隨機），畫面會顯示 5 碼房號。
2. 另一方輸入房號「加入房間」，雙方同時進入對局。
3. 終局後雙方都按「再來一局」即交換先後手重賽；一方回到首頁後就不能再戰。

協定（MQTT 5，主題前綴 `sakurama-shogi/v1`）：

| 主題 | 用途 |
| --- | --- |
| `room/<房號>/info` | 房主的保留訊息（15 分鐘到期），加入者用來確認房間存在；開局或取消時清除 |
| `room/<房號>/msg` | `join`、`start`、`move`、`resign`、`declare`、`timeout`、`hello`／`sync`（重連補步）、`rematch`、`leave` |
| `presence/<clientId>` | 上線時發布 `online`，遺囑訊息（LWT）為 `offline` |

- 每一手都由雙方的規則引擎各自驗證，收到不合法的棋步會直接忽略。
- 各方的計時以自己為準，隨棋步附上自己的剩餘時間；對手超時但沒有回報時，15 秒後判定超時勝。
- 對手斷線會顯示倒數，**60 秒內沒有回來即判勝**；自己斷線時會自動重連並向對手補齊漏掉的棋步。

## 功能

- **合法走法**：八種基本棋子、六種成駒、滑行阻擋、桂馬跳子、取子、持駒打入。
- **升變**：進入、離開或在敵陣三段內移動，可成／不成；步、香與桂的末段升變強制執行。
- **禁手防護**：阻止二步、打步詰、無處可走的打入、王手放置、自陷王手、越權與連續走兩手。
- **終局**：將死、無合法步、投了、時間到、千日手、連續王手千日手、入玉宣言、500 手持將棋、連線中斷。
- **計時**：無限時、5 分鐘＋10 秒讀秒、10 分鐘＋30 秒讀秒。每手讀秒重設；動畫不扣用時。
- **玩家**：名稱與 PNG/JPG/WebP 頭像（最大 5 MB，會在瀏覽器縮成 160×160）。
- **和服落子動畫**：五指關節、捏棋與收手；先後手分別使用象牙櫻花、紫藤櫻花袖子。
- **光影**：春日、夕暮、月夜三種光線；棋盤、棋子、手和袖子均支援投影；陰影與音效可開關。
- **固定視角**：拖曳和滾輪不旋轉棋盤；寬螢幕為三欄排版，手機維持左右頭像與上下持駒。

## 操作

1. 點自己的棋子，綠色位置是合法目的格；再次點該棋子可取消。
2. 點目的格落子；可升變時會出現「成／不成」選擇。
3. 取下的敵子回到自己的持駒區，並回復基本棋種。輪到自己時點持駒，再點合法空格打入。
4. 終局後點左側棋譜的任一手，或用下方箭頭逐手回顧。

棋盤格支援 Tab 聚焦與方向鍵移動焦點，Enter／空白鍵選取。Escape 可取消棋子選擇或關閉對話框。

## 規則選擇與來源

此遊戲採用平手將棋與**業餘 27 點入玉宣言制**：宣言者的玉在敵陣、未被王手、敵陣內除玉有至少 10 枚己子；敵陣己子與持駒計點（飛角各 5，其餘除玉各 1），先手至少 28 點、後手至少 27 點。未符合條件卻確認宣言會判負。此規則與職業賽的宣言制度有所不同，遊戲內指南有明確說明。

四次相同棋盤、持駒與手番構成千日手；如果循環間某方每次行棋都王手，該方判負。500 手後，在沒有王手時判持將棋。

參考日本將棋連盟資料：

- [棋子移動、取子與升變](https://www.shogi.or.jp/knowledge/shogi/02.php)
- [各棋種與成駒走法](https://www.shogi.or.jp/knowledge/shogi/03.php)
- [禁手說明](https://www.shogi.or.jp/knowledge/shogi/05.php)
- [千日手、王手、終局與持將棋](https://www.shogi.or.jp/match/taikyoku_rules/)
- [業餘入玉宣言法](https://www.shogi.or.jp/faq/rules/)

## 檔案結構

```
index.html          網頁入口（需放在根目錄）
launch.cmd          Windows 雙擊啟動
src/                遊戲程式
  app.js            首頁與模式流程、對局 UI、連線同步、設定、AI 排程
  style.css         版面與和風介面樣式
  rules/            純規則（無 DOM／WebGL 相依）
  ai/               電腦對手
  online/           MQTT 連線對戰
  scene/            3D 棋盤與和服手
scripts/            本機伺服器與啟動腳本
assets/             圖片與音效
vendor/             第三方函式庫（Three.js、MQTT.js）
docs/               功能與技術說明、瀏覽器截圖
tests/              unit／browser／differential 三類測試
```

| 檔案 | 功能 |
| --- | --- |
| `src/rules/engine.js` | 純將棋規則、SFEN／USI、合法步產生、終局、歷史與驗證恢復 |
| `src/rules/clock.js` | 主時間、每手讀秒與時間快照 |
| `src/rules/record.js` | UTF-8 KIF 匯出 |
| `src/ai/ai.js`、`src/ai/ai-worker.js` | 限時迭代加深搜尋，在背景工作執行 |
| `src/online/net.js` | MQTT 房間：建立／加入、訊息收發、上線狀態與遺囑訊息 |
| `src/scene/scene.js` | 固定輕微透視傾角（後手時翻轉）、3D 棋盤、棋子、合法格、光線及陰影 |
| `src/scene/hand.js` | 以距離場（SDF）＋ Surface Nets 生成一體成形的手部網格（掌骨、指節、拇指根、手腕平滑相連），自動計算蒙皮權重與指節／指尖膚色；閒置時才建模、不拖慢載入；花紋和服袖子與捏子、提子、落子、收手動畫 |
| `src/app.js` | 首頁與模式流程、對局 UI、連線同步、設定、升變與終局視窗、AI 排程 |

| `scripts/server.mjs` | 零依賴靜態檔案伺服器（`npm start`） |

| `vendor/` | 本地 Three.js 0.180.0（`LICENSE`）與 MQTT.js 5.15.2 瀏覽器 ES 模組（`LICENSE-mqtt.md`），皆為 MIT 授權 |

棋盤使用索引 `row × 9 + column`；先手 side=0、向上，後手 side=1、向下。規則引擎沒有 WebGL 或 DOM 相依，可獨立測試與重用。

## 驗證

安裝開發依賴（僅測試需要）：

```sh
npm install
npm test
```

目前共有 **18 項規則／計時測試**，包括初始局面的 30、900、25,470 節點合法步樹驗證、所有棋種、取子與成駒、打步詰、王手、將死、千日手、宣言法及讀秒。

網站啟動後：

```sh
npm run test:browser
node tests/browser/edge-browser.mjs
npm run test:online
```

使用本機 Microsoft Edge headless 測試首頁與各模式流程、離開確認、設定視窗、電腦回應、違規阻止、升變／不成／強制升變、取子與打入、悔棋、投了、將死、超時、終局回顧與 KIF、玩家資料與偏好保存、後手翻轉、取消過期 AI 工作、提示、固定視角與手機排版。`test:online` 會開兩個瀏覽器透過預設的公開 broker 實際建立與加入房間、同步棋步、投了、交換先後手再戰與離開，需要網路。

開發時可用 `http://127.0.0.1:4174/?sfen=<SFEN>` 從指定局面開始同機對局。

另與獨立套件 python-shogi 1.1.1 比對 **1,736 個種子生成的中盤局面**，每一局面的合法步集合均一致：

```sh
node tests/differential/differential-fixtures.mjs
python -m pip install python-shogi==1.1.1
python tests/differential/differential.py
```

Python 套件僅用於獨立交叉驗證，不是遊戲執行依賴。包含升變與打入的 KIF 已經由獨立 KIF 讀取器驗證。
